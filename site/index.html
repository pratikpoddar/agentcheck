For the Worldwide Agentic Web · MVP spec 0.2

Will other agents be able to call your site?

Paste an agentic website URL. AgentCheck reads its manifest, network and headers exactly the way a calling browser does, checks 34 rules from the spec, and tells you what to fix, with the snippet to paste.

Try:

No key needed for the check. It runs in your browser and only reads public files.

1

Finds the manifest

From a site, network or manifest URL, it locates agent-manifest.json and the exact network you named, the way the spec's peer protocol does.

2

Checks what callers see

CORS, HTTPS, router and peer policy, the data-only network, front agent, schemas, secrets, links and the action bridge, using the reference runtime's own parser and validator.

3

Explains and test-drives

Its agent network turns failures into a fix plan for your host, and can load your network as a peer and run it here, on your key, after you approve.

Ask AgentCheck's agents

Two agents run in your browser: a desk agent that checks and explains, and a fix writer that turns failures into steps for your host. Ask for a live test and they load the checked site's own network as a peer.

Your messages and the reports go to the LLM provider you choose in the settings below, with your key, which stays in this browser. Before any other site is contacted, you approve a card.

Use it where you build

Command line

Same checker, from Node 22+. Exits 1 when a MUST rule fails.

npx github:pratikpoddar/agentcheck https://your-site.example/your_network

GitHub Action

Fail a deploy that would break your callers.

- uses: pratikpoddar/agentcheck@v0
  with:
    url: https://your-site.example/your_network

From your agent network

Call AgentCheck before you link a partner. Add the network URL to an agent's tools and the origin to allowed_peers.

"tools": ["https://agentcheck.netlify.app/agentcheck"]

MCP server

Streamable HTTP, CORS open, no key. Tools: check_site, explain_rule, cors_fix.

{"url": "https://agentcheck.netlify.app/mcp",
 "tools": ["check_site"]}
