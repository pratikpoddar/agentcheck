Starter · MVP spec 0.2

Make your site an open agentic website.

Answer a few questions. AgentCheck writes your agent manifest, a two-agent network, the CORS rule for your host and a chat page, then checks them against every rule before you download. Upload the folder and other sites' agents can call yours.

More options

Nothing leaves your browser. The check runs here, on the files as they'll be served.

Files follow the Worldwide Agentic Web MVP spec and include the reference browser runtime (Apache-2.0, unchanged).
